# KAORI Website v0.1.0 — Stable Release

First stable public website release — 18 October 2026.

KAORI Website presents the KAORI infrastructure-operations platform and a public path to explore its operational model before entering the authenticated application. The maintainer accepted the publicly deployed RC.10 iteration.

## Highlights

- Branded, responsive KAORI Violet homepage with official artwork and light/dark support
- Evidence-led **How KAORI Works** journey: authoritative sources, context, committed evidence, and governed decisions
- Operating principles, capability domains, illustrative integration discovery, and an explicit conceptual product experience
- Accessible navigation, non-login platform exploration, and correct handoff to `https://app.kaori.cloud`
- Canonical, Open Graph/Twitter, JSON-LD, robots.txt and sitemap metadata
- Developer-oriented README, DevContainer, reproducible validation and governed delivery documentation
- Refined responsive copy, typography and concise editorial Violet quotes
