# KAORI Website v0.1.2

A reliability-focused stable release for the public KAORI Website. This
version carries forward the reviewed site experience and improves confidence
in how accepted website builds become production releases.

## Highlights

The public website is delivered from the **same signed image that passed
staging UAT**, rather than rebuilding a different image for production.
Production approval and verification remain separate from code review.

## Improvements

- Preserves the exact accepted Release Candidate image digest when publishing
  the stable version, allowing operators to trace a release to its tested build.
- Verifies the already-running website, retained deployment receipt and
  supporting provenance before finalizing stable release metadata.
- Maintains separate approval for production publication, even when source
  validation and staging quality checks have succeeded.

## Fixes

- Corrects incompatible GitHub API curl preflight flags in the stable promotion
  path, so the existing fail-closed checks can run as intended.

## Known Limitations

- The public website is informational, not an authenticated infrastructure
  operations dashboard.
- Staging and production governance currently share one public Website runtime;
  the stable release does not imply a separate production server was provisioned.
- The immutable image's build identity retains its original RC version. The
  public GitHub release tag is the stable version, **v0.1.2**.
