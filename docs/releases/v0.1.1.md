# KAORI Website v0.1.1 — Stable Release

Public website visual refinement, browser regression hardening and safer shared-edge release handling.

This release promotes **the existing, signed and publicly deployed `v0.1.1-rc.3` OCI image**, without rebuilding or mutating an image tag. Publication is authorized only after the maintainer accepts the public website UAT, the promotion PR to `main` is reviewed, and exact-main Full Admission (including browser and container checks) passes.

## Changes

- Clearer mobile Hero/Architecture copy and readable, unclipped capability cards.
- Deliberate two-row KAORI acronym wrapping in Hero and Footer, with guarded 390px layout stability.
- More compact mobile Ecosystem principle panel, scrollable accessible category filters, clearer visual flow and full-width Product Experience CTA.
- Desktop Product Experience disclaimer lock aligned with its authentication text in both themes.
- Explicit public website edge-public reattachment option in the canonical Release Deployment workflow, with fail-closed preflight before a public container replacement and three-domain HTTPS readiness verification afterward.

All external integrations remain authoritative. The illustrative product preview is not live infrastructure data. The public website is separate from the authenticated KAORI Application and automation services.

## Rollback and boundaries

The prior stable release [`v0.1.0`](https://github.com/OXY7O/kaori-website/releases/tag/v0.1.0) and its signed OCI image `sha256:8205ec3f66ed5c0eabc880f3fc49eb002da962b9c21242458c4ebc86a87dc930` remain available as a historical rollback authority, subject to the existing shared-edge operator procedure and verified domain readiness. No DNS, Nginx, Certbot, KAORI Application or automation deployment is performed by the stable GitHub Release step.

The automated browser and origin-host HTTPS checks do **not** establish field Core Web Vitals, actual iOS Safari or independently verified full TLS/Host/SNI/renewal acceptance; maintainers must retain those limits in the UAT record.
